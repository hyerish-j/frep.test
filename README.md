# 프렙 카페 운영관리

EPIC 1: 판매 등록·수정·삭제, 일/월 메뉴 수익성, 종료일 재료 잔량 조회 및 IndexedDB 지속 저장.

## 실행

Node.js 24.x 환경에서 다음을 실행한다. Windows PowerShell에서 실행 정책이 npm.ps1을 막으면 `npm.cmd`를 사용한다.

```text
npm ci
npm run dev
```

확인 주소: http://127.0.0.1:5173/#/sales

`npm run typecheck`, `npm run lint`, `npm run test`, `npm run test:e2e`, `npm run build`로 검사한다. 브라우저 자동 검사는 설치된 Chrome을 사용하고 매 검사마다 독립된 임시 브라우저 자료를 사용한다. 운영자 화면의 자료를 변경하지 않는다.

## 저장과 범위

기록은 해당 주소의 브라우저 프로필에 저장된다. `localhost`와 `127.0.0.1`, 다른 포트·브라우저·프로필은 서로 다른 저장소다. 사용자 테스트 동안 같은 주소를 사용하고 사이트 데이터를 삭제하지 않는다. 전체 백업·복원은 아직 EPIC 3 구현 전이다.

제공 JSON은 가상 샘플이며 첫 실행에만 반영한다. 공개 배포 시 샘플 파일은 공개로 내려받을 수 있다. 실제 운영 자료와 백업을 소스·배포 파일에 넣지 않는다. 서버에 운영 기록을 전송하지 않는다.

매장 손익·비용 관리는 EPIC 2, 입고·폐기·실측 입력 및 백업·복원은 EPIC 3 대상이다. 아직 구현하지 않은 기능 버튼을 가짜 동작으로 제공하지 않는다.

## 사용자 확인

개발 계획과 상태는 `docs/04_개발계획.md`, 자동 검사 및 사용자 확인 기록은 `docs/05_테스트결과.md`에 기록한다. 자동 검사 통과만으로 EPIC을 완료 처리하지 않는다. 사용자의 화면 확인이 통과한 EPIC만 완료로 표시한다.
